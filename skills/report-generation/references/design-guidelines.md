# Report Design Guidelines

- Use the reusable HTML and CSS templates as the source of truth.
- Preserve readable margins and spacing on letter-size pages.
- Use a strong header color for table headings and a light alternate row color.
- Use at least 10-point body text and 13-point section headings.
- Keep all report figures sourced from sales analysis; do not recalculate them.
- Footer text must remain concise and include the report title and page number.
